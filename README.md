# 사회적협동조합 플러스평택 홈페이지 - v5

방문자 중심으로 대폭 단순화한 버전입니다.

## v5 디자인 원칙
- 홈페이지는 설명서가 아니라 서비스의 입구로 사용
- 첫 화면에서 기관 철학을 한 문장으로 전달
- 방문자는 '무엇을 찾으세요?'에서 바로 필요한 서비스로 이동
- 평택 함께지도와 평택형 사회주택은 홈페이지에 직접 끼워 넣지 않고 전용 서비스로 연결
- 상세 미션·비전·인사말·연혁과 협동플랫폼 층별정보는 필요할 때 펼쳐보기
- 공지와 사진은 최신 3건만 노출
- 관리자/Supabase 기능은 그대로 유지

## 관리자
`admin.html`에서 공지사항과 여러 장의 사진을 관리할 수 있습니다.
팩스번호가 생기면 관리자 화면에서 입력하면 홈페이지에 표시되고, 비워두면 자동으로 숨겨집니다.
