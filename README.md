# 사회적협동조합 플러스평택 공식 홈페이지 v5

## 이번 버전에 반영한 내용
- 공식 로고, 대표전화, 이메일, 주소, 이사장, 설립일
- 사업자등록번호와 법인등록번호
- 운영시간 및 주차안내
- 정관 취지를 반영한 목적·미션·비전·핵심가치
- 이사장 인사말
- 평택지역자활센터 / 도우누리평택노인재활주간보호센터 / 평택형 사회주택 / 플러스평택협동플랫폼
- 평택형 사회주택 전용 시스템 연결
- 플러스평택협동플랫폼 층별 입주기관
- 주요 연혁
- 공지사항·갤러리 관리자 페이지 기본 구현
- 갤러리 사진 다중 업로드 + 사진별 제목/설명 입력

## 현재 홈페이지 상태
`assets/supabase-config.js`가 비어 있어도 홈페이지는 정적 버전으로 정상 작동합니다.
관리자 기능을 사용하려면 `docs/관리자_설정가이드.md`에 따라 Supabase를 연결하세요.

## 중요한 보안 원칙
- service_role 키는 절대로 GitHub나 HTML에 넣지 않습니다.
- 공개 저장소에는 참여주민 명단, 상담기록, 주민등록번호 등을 올리지 않습니다.
- 일반 사용자의 회원가입은 사용하지 않습니다.
- 관리자 계정은 승인된 2명만 등록합니다.


## v4 변경사항
- 평택 함께지도(사회연대경제·공공일자리 지도) 홈페이지 내 탑재 + 전체화면 바로가기
- PC 화면의 시각 요소와 섹션 간격을 정리하여 밀도를 낮춤
- 모바일 한글 단어가 어색하게 중간에서 끊기지 않도록 줄바꿈 규칙 개선
- 공지와 갤러리를 하나의 ‘소식과 활동’ 영역으로 통합
- 관리자 화면에서 팩스번호를 추후 입력·수정 가능
- 팩스번호가 비어 있으면 공개 홈페이지에서 자동 숨김


## v5 주요 변경
- 정식 명칭 `사회적협동조합 플러스평택` 표기 강화
- PC 헤더 로고와 기관명 확대
- 바로찾기 5개 서비스 아이콘 메뉴 추가
- 1080/820/760/480/360px 반응형 구간 최적화
- 모바일 한글 단어 단위 줄바꿈과 터치영역 개선
- 화면 폭에 따라 카드 수와 레이아웃이 자동 변하는 유동형 구조 적용
