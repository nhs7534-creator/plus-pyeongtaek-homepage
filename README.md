# 사회적협동조합 플러스평택 홈페이지

GitHub Pages에서 운영할 수 있는 정적 홈페이지 1차 버전입니다.

## 가장 먼저 수정할 파일

`assets/config.js` 한 파일에서 기관명, 연락처, 미션·비전, 사업, 부설기관, 연혁과 공지 내용을 수정할 수 있습니다.

## 파일 구조

- `index.html`: 홈페이지 화면
- `privacy.html`: 개인정보처리방침
- `404.html`: 잘못된 주소 안내
- `assets/config.js`: 기관 콘텐츠
- `assets/style.css`: 디자인
- `assets/app.js`: 화면 동작
- `docs/운영체크리스트.md`: 공개 전 점검표

## 보안 원칙

- 이 저장소에 비밀번호를 넣지 않습니다.
- Supabase `service_role` 키를 넣지 않습니다.
- 참여주민 명단, 상담기록, 주민등록번호 등 개인정보를 올리지 않습니다.
- 초상권 동의 여부가 불명확한 사진은 사용하지 않습니다.
