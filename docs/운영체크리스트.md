# 홈페이지 공개 전 운영 체크리스트

## 필수 콘텐츠

- [ ] 이사장 성명과 인사말 확인
- [ ] 법인 설립일과 연혁 확인
- [ ] 주소·전화·팩스·이메일 확인
- [ ] 주요 사업 명칭과 설명 확인
- [ ] 부설기관 명칭과 링크 확인
- [ ] 개인정보 보호책임자 정보 입력
- [ ] 로고 및 사진 사용권 확인

## 기능 점검

- [ ] PC 크롬에서 첫 화면 확인
- [ ] 갤럭시와 아이폰에서 메뉴 확인
- [ ] 전화 링크 작동 확인
- [ ] 이메일 링크 작동 확인
- [ ] 네이버지도 링크 확인
- [ ] 개인정보처리방침 링크 확인
- [ ] 오타와 잘못된 숫자 확인

## 보안·운영

- [ ] 저장소에 비밀번호나 비밀키가 없는지 확인
- [ ] 개인정보가 포함된 사진이나 문서가 없는지 확인
- [ ] GitHub 계정 2단계 인증 적용
- [ ] 월 1회 전체 파일 백업
- [ ] 담당자 변경 시 계정과 매뉴얼 인계
