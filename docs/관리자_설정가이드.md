# 관리자 기능 설정 가이드 — 초보자용

관리자 기능은 공지사항과 사진을 직원이 직접 등록하기 위한 기능입니다.
대표 관리자 이메일은 `pluspt1007@kakao.com`, 총 관리자 수는 1명으로 설계했습니다.

## 1. Supabase 프로젝트 만들기
1. supabase.com 접속 후 로그인
2. New project 클릭
3. 프로젝트명 예: `plus-pyeongtaek`
4. 데이터베이스 비밀번호는 강하게 설정하고 별도로 보관
5. Region은 한국과 가까운 지역 선택

## 2. 데이터베이스 구조 만들기
1. Supabase 왼쪽 `SQL Editor`
2. `New query`
3. 이 홈페이지에 포함된 `supabase-setup.sql` 전체 복사
4. Run 클릭

## 3. 대표 관리자 계정 만들기
1. `Authentication` → `Users`
2. `Add user` → `Create new user`
3. 관리자 이메일과 비밀번호 입력 (대표 관리자: `pluspt1007@kakao.com`)
4. 생성된 사용자 행에서 UUID를 확인
5. SQL Editor에서 아래를 실행

```sql
insert into public.admin_users(user_id,email)
values ('대표관리자-UUID','pluspt1007@kakao.com');
```

## 4. 일반 회원가입 막기
Authentication → Providers → Email 설정에서 일반 사용자의 Sign ups 허용을 끕니다.
홈페이지는 일반 회원가입이 필요하지 않습니다.

## 5. 홈페이지에 Supabase 연결값 넣기
Supabase `Project Settings` → `API`에서 Project URL과 Publishable/anon key를 확인합니다.
`assets/supabase-config.js`에서 다음 두 값만 바꿉니다.

```js
url: "https://실제프로젝트주소.supabase.co",
anonKey: "실제-publishable-or-anon-key"
```

`service_role` 키는 절대로 넣지 않습니다.

## 6. 관리자 사용
홈페이지 주소 뒤에 `/admin.html`을 붙여 접속합니다.
- 공지사항: 제목, 분류, 내용, 게시일, 중요공지 등록
- 갤러리: 여러 장을 한 번에 선택 → 사진별 제목과 설명 입력 → 일괄 등록
- 업로드 이미지는 브라우저에서 최대 약 1800px로 자동 축소 후 저장

## 7. 관리자 교체
퇴사·인사이동 시:
1. `admin_users`에서 해당 관리자 삭제
2. Authentication Users에서도 계정 삭제
3. 새 관리자 계정 생성 및 등록

## 8. 운영 원칙
- 주민 개인정보가 있는 사진 업로드 금지
- 초상권 확인된 사진만 게시
- 월 1회 공지·갤러리 백업 점검
- 관리자 비밀번호 공유 금지


## 기관정보 관리
관리자 로그인 후 **기관정보** 탭에서 팩스번호를 입력할 수 있습니다. 팩스번호가 없는 동안은 빈칸으로 두면 공개 홈페이지에서 해당 항목이 자동으로 숨겨집니다. 추후 팩스가 생기면 번호를 입력하고 저장하면 됩니다.
